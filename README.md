# Kalkulator Bunga Sederhana (Simple Interest Calculator)

Proyek ini adalah kalkulator sederhana yang dirancang untuk menghitung bunga pinjaman berdasarkan pokok, suku bunga, dan periode waktu tertentu. Proyek ini dikembangkan sebagai bagian dari latihan praktis pengelolaan repositori di GitHub.

## Fitur Utama
- Menghitung bunga pinjaman (*simple interest*) secara akurat.
- Antarmuka baris perintah (*command-line interface*) berbasis Bash.
